Whisper Speech-to-Text 

A simple speech-to-text project using OpenAI Whisper and Hugging Face Transformers to transcribe English audio.

Technologies

Python

Hugging Face Transformers

OpenAI Whisper

PyTorch

Google Colab

CUDA / GPU

How It Works

Audio File ↓ Whisper Model ↓ Speech Recognition ↓ Text Transcription 

Model

openai/whisper-medium.en

The project uses GPU acceleration with CUDA for transcription.

Usage

Place an audio file in your Google Drive, update the file path in the notebook, and run the notebook to generate the transcription.

Purpose

A small practical project for learning Speech-to-Text, Whisper, Hugging Face Transformers, and GPU inference.
